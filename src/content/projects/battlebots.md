# battlebot

1-3 lb Personal Battlebot for IEEE@UH Robotics

![Preview](https://raw.githubusercontent.com/kennyspezi/battlebots/main/preview.png)

## Overview

This repository contains the design files, documentation, and development history of my personal combat robot projects. Future updates will include more detailed schematics, wiring diagrams, and comprehensive build documentation.

## Project Timeline

### 2024-2025: Shell Spinner

The first iteration of this project was a shell spinner design, developed throughout the 2024-2025 season. Features a brushless motor-driven spinning shell with simplified planetary gear system (single planet and ring gear). See [shellspinner/](https://github.com/kennyspezi/battlebots/blob/main/shellspinner/) for CAD files and detailed design.

### 2026: New Design

Starting in 2026, this project is evolving with a completely new robot design to explore different combat strategies and mechanisms. Check out [Design Decisions](https://github.com/kennyspezi/battlebots/blob/main/docs/DESIGN_DECISIONS.md)
